# Source catalog

[Search the catalog](index.html), [download CSV](catalog.csv), or [inspect JSON](catalog.json).

The catalog includes all public source records and HTTP/HTTPS anchors retained in the ten included research documents. It combines 20 records from the India–Pakistan current review, 60 from the comparative report, 44 from the literature foundation, 24 from the archived halal discovery pass, 76 from the public-source Phase One edition, 188 from the October continuation, 95 from the working paper's audited register, and additional links preserved in the report text, orientation briefings and survey source page. Duplicate explicit DOI or normalized URL identities are grouped with their document occurrences retained. Different URLs can still refer to the same underlying publication; no fuzzy title matching is performed.

The original registers retain the full annotations and source IDs used in each report:

- [India–Pakistan review register](../research/india-pakistan/source-register.json).
- [Comparative protein source register](../research/comparative-protein/source-register.json).
- [AI/protein literature source register](../research/ai-protein/source-register.json).
- [Phase One halal public-source register](../research/halal-cultivated/phase1/source-register.json).
- [October continuation register](../research/halal-cultivated/phase1-continuation/source-register.json).
- [Working paper register](../research/halal-cultivated/paper/source-register.json), with audit verdicts.
- [Archived halal discovery register](../research/halal-cultivated/archive/discovery-pass/source-register.json).
- [Alternative meat survey source page](../research/protein-survey-data/index.html), with structured data in `survey-data.json` and CSV files.
- [Orientation source-link extraction](../research/orientation/sources.json).

Catalog IDs are generated navigation identifiers and may change after rebuilding. Cite the original document's source ID or DOI. The CSV is a compact index; the original registers contain fuller access, methods, limitations, and funding notes.

The catalog is complete relative to the public references retained in this curated file tree. It is not a bibliography of every private working document, every search result previously encountered, every Git-history object, or the entire field. External URLs have not been freshly resolved in this repository-preparation pass. Third-party originals are linked, not bundled. See [rights and reuse](../RIGHTS-AND-REUSE.md).
