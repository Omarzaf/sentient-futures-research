# Source catalog

[Search the catalog](index.html), [download CSV](catalog.csv), or [inspect JSON](catalog.json).

The catalog includes all public source records and HTTP/HTTPS anchors retained in the six included research documents. It combines 20 records from the India–Pakistan current review, 60 from the comparative report, 44 from the literature foundation, and additional links preserved in the report text and orientation briefings. Duplicate explicit DOI or normalized URL identities are grouped with their document occurrences retained. Different URLs can still refer to the same underlying publication; no fuzzy title matching is performed.

The original registers retain the full annotations and source IDs used in each report:

- [India–Pakistan review register](../research/india-pakistan/source-register.json).
- [Comparative protein source register](../research/comparative-protein/source-register.json).
- [AI/protein literature source register](../research/ai-protein/source-register.json).
- [Orientation source-link extraction](../research/orientation/sources.json).

Catalog IDs are generated navigation identifiers and may change after rebuilding. Cite the original document's source ID or DOI. The CSV is a compact index; the original registers contain fuller access, methods, limitations, and funding notes.

The catalog is complete relative to the public references retained in this curated collection. It is not a bibliography of every private working document, every search result previously encountered, or the entire field. External URLs have not been freshly resolved in this repository-preparation pass. Third-party originals are linked, not bundled. See [rights and reuse](../RIGHTS-AND-REUSE.md).
