# MMM reference scope and differences

The [Observatory reference](observatory-reference.html) is Muhammad Umar Zafar's existing MMM Entry III. Its original location is [Omarzaf/MMM](https://github.com/Omarzaf/MMM/tree/main/03-pakistan-ai-policy-observatory). It demonstrates a substantial research entry's frame, figures, captions, marginalia and evidence navigation. Its Pakistan AI policy data, conclusions and dates are unrelated to this paper.

The earlier local package retargeted twelve relative artifact links to their original public repository paths. This repository edition additionally disables the optional Google Fonts import. No research text, geometry or interaction code was otherwise changed. Provenance hashes record both the source-package version and this edition. The unrelated datasets and downloads are not bundled.

The intended typefaces remain Newsreader and IBM Plex Mono. Their binaries are not supplied, so this reference renders using fallbacks unless the builder supplies appropriately licensed font files. Do not infer that fallback typography is the exact MMM target. No script or font download is required to read the handoff.

Follow [the design brief](../DESIGN-BRIEF.md) when examples conflict: keep copper fixed across themes, use stronger ink for essential labels, preserve the specified reading frame without overflow, and keep the manuscript's own voice. Older specimen cards and placeholder prompt examples are omitted. Component JSX is source for learning the design, not an instruction to add React or an editor runtime. The original token files are under `../mmm/foundations/` in this edition.

The [content license](CONTENT-LICENSE.txt) and separate [tools-directory license](TOOLS-LICENSE.txt) are retained with their original scopes. Third-party sources retain their own terms. No new screenshot capture, live-site validation, or package-wide license is claimed.
